🏥 Healthcare Performance Analytics

📊 Project Overview

This project analyzes healthcare data using SQL Server to uncover insights into financial performance, patient activity, insurance receivables, procedure volumes, and physician productivity.

The analysis demonstrates how SQL Server Management Studio (SSMS) can be used to transform structured healthcare data into meaningful business and operational insights that can support informed decision-making.

---

🎯 Business Questions

The analysis focused on key questions around:

- 💰 What is the overall financial performance of the healthcare organization?
- 🧾 Which insurance payers have the highest outstanding receivables?
- 🩺 Which medical specialties and procedures have the highest activity?
- 🏥 Which locations have the highest patient volume?
- 👨‍⚕️ Which physicians demonstrate the highest productivity?

---

🛠️ Tools & Technologies

- 🗄️ SQL Server Management Studio (SSMS) — Data querying and analysis
- 📊 Microsoft Excel — Dashboard development and data visualization

---

🗂️ Dataset

The project uses a structured healthcare dataset containing information relating to:

- 👥 Patients
- 👨‍⚕️ Physicians
- 🩺 Medical specialties
- 💉 Procedures
- 🏥 Locations
- 🏦 Insurance payers
- 📅 Dates
- 💳 Healthcare transactions

The data was analyzed using SQL Server to generate the metrics and insights presented in the project.

---

🔍 Key Analysis Areas

💰 Financial Performance

Analyzed healthcare charges, payments, adjustments, and outstanding accounts receivable to assess the organization's financial position.

🧾 Insurance Receivables

Examined outstanding balances by insurance payer to identify payers contributing most significantly to accounts receivable.

🩺 Procedure & Specialty Performance

Analyzed procedure volumes across medical specialties to identify areas with higher levels of healthcare activity.

🏥 Patient Volume

Compared patient activity across healthcare locations to identify facilities serving the largest patient populations.

👨‍⚕️ Physician Productivity

Evaluated physician activity to identify the highest-performing physicians based on procedure volume.

---

📌 Key Findings

The analysis generated several notable findings:

- 💰 Gross charges: Approximately $1.47 million
- 💵 Payments: Approximately $703,613
- 📉 Adjustments: Approximately $716,683
- 🧾 Outstanding accounts receivable: Approximately $51,971
- 🏦 Commercial insurance had the highest outstanding receivable balance.
- 🩺 Internal Medicine recorded the highest procedure volume.
- 🏥 Angelstone Community Hospital had the highest patient volume.
- 👨‍⚕️ Dr. Hendricks recorded the highest physician productivity based on the analysis.
